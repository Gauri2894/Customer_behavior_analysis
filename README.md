# 📊 Customer Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior to identify purchasing patterns, repeat customer behavior, subscription trends, and product category performance.

The project uses SQL, Python, and Power BI to transform customer data into meaningful business insights.

## 🎯 Objectives

- Understand customer purchasing patterns.
- Analyze repeat customer behavior.
- Investigate subscription status and customer preferences.
- Compare purchasing behavior across product categories.
- Present key findings through interactive visualizations.

## 🛠️ Tools and Technologies

- **SQL:** Business queries and customer analysis
- **PostgreSQL:** Database management and querying
- **Python:** Data analysis and preprocessing
- **Pandas and NumPy:** Data manipulation
- **Power BI:** Dashboard development and visualization

## 🔄 Project Workflow

1. Data loading and inspection.
2. Data cleaning and preprocessing using Python.
3. SQL-based analysis of customer shopping behavior.
4. Exploratory data analysis.
5. Power BI dashboard development.
6. Interpretation of findings and business recommendations.

## 📂 Project Structure

- `dataset/` — Dataset files, if redistribution is permitted
- `sql/` — SQL queries
- `python/` — Python notebook
- `powerbi/` — Power BI dashboard


## 📈 Key Business Questions

- What purchasing patterns can be observed among customers?
- How does subscription status relate to purchasing behavior?
- How do repeat customers behave?
- Which product categories generate the most revenue?
- What insights could help improve customer engagement?

## 💡 Key Findings

The analysis focused on customer purchasing patterns, subscription behavior, repeat purchases, and product category performance.

- **Customer Purchasing Patterns:** Analyzed customer purchasing behavior to identify trends in purchase amounts and product preferences.
- **Repeat Customer Behavior:** Examined repeat purchasing patterns to understand customer engagement and buying frequency.
- **Subscription Analysis:** Compared purchasing behavior between subscribed and non-subscribed customers.
- **Product Category Performance:** Analyzed purchase amounts across product categories to identify categories contributing the most revenue.
- **Customer Insights:** Used SQL queries and Python-based exploratory data analysis to identify patterns that can support data-driven business decisions.
